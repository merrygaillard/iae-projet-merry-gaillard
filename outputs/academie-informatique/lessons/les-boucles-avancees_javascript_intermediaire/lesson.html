Les boucles avancées en JavaScript

Durée estimée : 18 minutes | Niveau : Intermédiaire

Introduction

Vous connaissez déjà for, while et do...while. Maintenant, découvrez les boucles modernes et les méthodes de tableau qui rendent le code plus lisible et expressif. Ces outils vous permettront d'écrire du JavaScript plus propre et fonctionnel.

1. for...in : itérer sur les propriétés d'un objet

for...in parcourt toutes les propriétés énumérables d'un objet. C'est idéal pour les objets, mais à éviter pour les tableaux (utilisez for...of à la place).

Syntaxe

for (let clé in objet) {
  console.log(clé);        // nom de la propriété
  console.log(objet[clé]); // valeur de la propriété
}

Exemple 1 : Afficher les propriétés d'un objet

const utilisateur = {
  nom: 'Alice',
  âge: 28,
  ville: 'Paris'
};

for (let clé in utilisateur) {
  console.log(`${clé}: ${utilisateur[clé]}`);
}

// Résultat :
// nom: Alice
// âge: 28
// ville: Paris

Exemple 2 : Calculer la somme des propriétés numériques

const scores = {
  math: 95,
  français: 88,
  histoire: 92
};

let total = 0;
for (let matière in scores) {
  total += scores[matière];
}

console.log(`Total : ${total}`);       // Total : 275
console.log(`Moyenne : ${total / 3}`); // Moyenne : 91.67

⚠️ Attention : for...in n'est pas recommandé pour les tableaux. Il parcourt toutes les propriétés, pas seulement les indices. Utilisez plutôt for...of (voir section 2).

2. for...of : itérer sur les valeurs d'un itérable

for...of est le choix moderne pour parcourir des tableaux, chaînes de caractères, et autres itérables. Contrairement à for...in, il itère sur les valeurs, pas les clés.

Syntaxe

for (let valeur of itérable) {
  // faire quelque chose avec valeur
}

Exemple 1 : Parcourir un tableau

const couleurs = ['rouge', 'vert', 'bleu'];

for (let couleur of couleurs) {
  console.log(couleur);
}

// Résultat :
// rouge
// vert
// bleu

Exemple 2 : Parcourir une chaîne

const mot = 'JavaScript';

for (let lettre of mot) {
  console.log(lettre);
}

// Résultat : J, a, v, a, S, c, r, i, p, t (chacun sur une ligne)

Exemple 3 : Accumulation avec for...of

const nombres = [10, 20, 30, 40];
let somme = 0;

for (let nombre of nombres) {
  somme += nombre;
}

console.log(`Somme : ${somme}`); // Somme : 100

3. forEach() : exécuter une fonction pour chaque élément

forEach() est une méthode de tableau qui applique une fonction à chaque élément. Elle est plus courte que les boucles traditionnelles et très lisible.

Syntaxe

tableau.forEach((element, index) => {
  // element : la valeur actuelle
  // index : l'indice de l'élément (optionnel)
});

Exemple 1 : Afficher chaque élément

const fruits = ['pomme', 'banane', 'orange'];

fruits.forEach((fruit) => {
  console.log(fruit);
});

// Résultat :
// pomme
// banane
// orange

Exemple 2 : Utiliser l'index

const tâches = ['faire courses', 'nettoyer', 'cuisiner'];

tâches.forEach((tâche, index) => {
  console.log(`${index + 1}. ${tâche}`);
});

// Résultat :
// 1. faire courses
// 2. nettoyer
// 3. cuisiner

Différence clé : Contrairement à for et while, forEach() ne peut pas être arrêtée avec break ou continue. Si vous avez besoin de ces contrôles, utilisez une boucle traditionnelle ou for...of.

4. map() : transformer chaque élément

map() crée un nouveau tableau en appliquant une fonction à chaque élément. L'original n'est pas modifié.

Syntaxe

const nouveauTableau = tableau.map((element) => {
  return transformationDe(element);
});

Exemple 1 : Doubler chaque nombre

const nombres = [1, 2, 3, 4, 5];

const doublés = nombres.map((n) => n * 2);

console.log(doublés); // [2, 4, 6, 8, 10]
console.log(nombres); // [1, 2, 3, 4, 5] (inchangé)

Exemple 2 : Transformer des objets

const utilisateurs = [
  { nom: 'Alice', âge: 28 },
  { nom: 'Bob', âge: 35 },
  { nom: 'Charlie', âge: 22 }
];

const noms = utilisateurs.map((user) => user.nom);

console.log(noms); // ['Alice', 'Bob', 'Charlie']

Exemple 3 : Convertir les types

const prix = ['10.50', '25.00', '5.99'];

const prixNombres = prix.map((p) => parseFloat(p));

console.log(prixNombres); // [10.5, 25, 5.99]

5. filter() : sélectionner les éléments qui correspondent

filter() crée un nouveau tableau contenant seulement les éléments qui satisfont une condition.

Syntaxe

const nouveau = tableau.filter((element) => {
  return condition(element);
});

Exemple 1 : Sélectionner les nombres pairs

const nombres = [1, 2, 3, 4, 5, 6, 7, 8];

const pairs = nombres.filter((n) => n % 2 === 0);

console.log(pairs); // [2, 4, 6, 8]

Exemple 2 : Sélectionner les objets selon un critère

const produits = [
  { nom: 'Laptop', prix: 1200 },
  { nom: 'Souris', prix: 25 },
  { nom: 'Clavier', prix: 80 },
  { nom: 'Écran', prix: 300 }
];

const produitsCher = produits.filter((p) => p.prix > 100);

console.log(produitsCher);
// [{nom: 'Laptop', prix: 1200}, {nom: 'Écran', prix: 300}]

Exemple 3 : Combiner map et filter

const notes = [45, 88, 92, 62, 78, 55, 95];

// D'abord filtrer les notes ≥ 70, puis les doubler
const bonnesNotes = notes
  .filter((note) => note >= 70)
  .map((note) => note * 2);

console.log(bonnesNotes); // [176, 184, 156, 190]

6. reduce() : accumuler une seule valeur

reduce() combine tous les éléments d'un tableau en une seule valeur. Utile pour calculer des sommes, produits, ou d'autres agrégations.

Syntaxe

const résultat = tableau.reduce((accumulateur, element) => {
  return nouvelAccumulateur;
}, valeurInitiale);

Exemple 1 : Somme des éléments

const nombres = [10, 20, 30, 40];

const somme = nombres.reduce((acc, n) => acc + n, 0);

console.log(somme); // 100

Comment ça marche :

  • Itération 1 : acc = 0, n = 10 → acc + n = 10
  • Itération 2 : acc = 10, n = 20 → acc + n = 30
  • Itération 3 : acc = 30, n = 30 → acc + n = 60
  • Itération 4 : acc = 60, n = 40 → acc + n = 100

Exemple 2 : Produit des éléments

const facteurs = [2, 3, 4, 5];

const produit = facteurs.reduce((acc, f) => acc * f, 1);

console.log(produit); // 120

Exemple 3 : Grouper des données

const ventes = [
  { produit: 'Laptop', montant: 1200 },
  { produit: 'Souris', montant: 25 },
  { produit: 'Laptop', montant: 1200 },
  { produit: 'Clavier', montant: 80 }
];

const total = ventes.reduce((acc, vente) => {
  acc[vente.produit] = (acc[vente.produit] || 0) + vente.montant;
  return acc;
}, {});

console.log(total);
// { Laptop: 2400, Souris: 25, Clavier: 80 }

Tableau comparatif : Quand utiliser quoi ?

Méthode Cas d'usage Retour
for...in Parcourir les propriétés d'un objet Pas de retour (parcours)
for...of Parcourir les valeurs d'un tableau ou chaîne Pas de retour (parcours)
forEach() Effectuer une action sur chaque élément (sans break/continue) undefined
map() Transformer chaque élément Nouveau tableau transformé
filter() Sélectionner les éléments qui correspondent à une condition Nouveau tableau filtré
reduce() Accumuler une seule valeur à partir de tous les éléments Valeur unique (nombre, objet, chaîne, etc.)

Cas d'usage concrets

Cas 1 : Traiter une liste de commandes

const commandes = [
  { id: 1, montant: 50, payée: true },
  { id: 2, montant: 120, payée: false },
  { id: 3, montant: 30, payée: true },
  { id: 4, montant: 200, payée: false }
];

// Montant total des commandes payées
const totalPayé = commandes
  .filter((cmd) => cmd.payée)
  .reduce((acc, cmd) => acc + cmd.montant, 0);

console.log(`Total payé : ${totalPayé}€`); // Total payé : 80€

// Montant moyen des commandes
const montantMoyen = commandes.reduce((acc, cmd) => acc + cmd.montant, 0) / commandes.length;

console.log(`Montant moyen : ${montantMoyen.toFixed(2)}€`); // Montant moyen : 100.00€

Cas 2 : Formater et filtrer une liste d'utilisateurs

const utilisateurs = [
  { nom: 'alice', email: 'alice@example.com', premium: true },
  { nom: 'bob', email: 'bob@example.com', premium: false },
  { nom: 'charlie', email: 'charlie@example.com', premium: true }
];

// Formater les noms des utilisateurs premium
const utilisateursPremium = utilisateurs
  .filter((u) => u.premium)
  .map((u) => ({ nom: u.nom.toUpperCase(), email: u.email }));

console.log(utilisateursPremium);
// [{nom: 'ALICE', email: 'alice@example.com'}, {nom: 'CHARLIE', email: 'charlie@example.com'}]

Points clés à retenir

  • for...in : Propriétés d'un objet (pas pour les tableaux)
  • for...of : Valeurs d'un tableau (moderne et lisible)
  • forEach(), map(), filter(), reduce() : Méthodes fonctionnelles pour les tableaux
  • map() crée un nouveau tableau (même taille)
  • filter() crée un nouveau tableau (potentiellement plus petit)
  • reduce() retourne une seule valeur (pas un tableau)
  • Vous pouvez chaîner ces méthodes : tableau.filter(...).map(...).reduce(...)
