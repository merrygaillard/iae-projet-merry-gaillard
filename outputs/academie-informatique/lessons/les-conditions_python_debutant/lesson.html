Les conditions en Python

Durée estimée : 14 minutes | Niveau : Débutant

Introduction

Imaginez que vous créez un jeu vidéo. Vous voulez que quelque chose se passe si le joueur a assez de points, et quelque chose d'autre sinon. Ou imaginez un programme bancaire : si le solde est suffisant, autorise le retrait ; sinon, refuse-le.

La réponse est les conditions. C'est la fondation de la logique en programmation : dire au programme « Si telle chose est vraie, fais ça ; sinon, fais autre chose ».

Qu'est-ce qu'une condition ?

Une condition est une question que vous posez à votre programme. La réponse est toujours soit Vrai (True), soit Faux (False).

Exemples de conditions :

  • « Est-ce que 5 est plus grand que 3 ? » → Vrai
  • « Est-ce que l'utilisateur a 18 ans ou plus ? » → Dépend
  • « Est-ce que mon mot de passe est correct ? » → Dépend

Les opérateurs de comparaison

Pour poser une question, vous avez besoin d'opérateurs de comparaison. Voici les principaux :

Opérateur Signification Exemple Résultat
== Égal à 5 == 5 True
!= Différent de 5 != 3 True
> Plus grand que 5 > 3 True
< Plus petit que 5 < 3 False
>= Plus grand ou égal 5 >= 5 True
<= Plus petit ou égal 5 <= 3 False

⚠️ Attention : Ne confondez pas == (comparaison) et = (affectation). == pose une question, = assigne une valeur.

La structure if (si)

La structure if dit : « Si la condition est vraie, exécute ce code ».

Syntaxe :

if condition:
    # Code à exécuter si la condition est True
    print("La condition est vraie")

Exemple 1 : Vérifier l'âge

age = 20
if age >= 18:
    print("Vous êtes majeur")

Explication : Si age est ≥ 18, le programme affiche « Vous êtes majeur ». Sinon, il ne se passe rien.

La structure if ... else (si ... sinon)

else signifie « sinon ». Elle s'exécute si la condition est fausse.

Syntaxe :

if condition:
    # Code si True
else:
    # Code si False

Exemple 2 : Majorité

age = 15
if age >= 18:
    print("Vous êtes majeur")
else:
    print("Vous êtes mineur")

Explication : Ici, age = 15, donc 15 >= 18 est False. Le programme exécute le bloc else et affiche « Vous êtes mineur ».

La structure if ... elif ... else

elif signifie « sinon si ». Elle permet de tester plusieurs conditions.

Syntaxe :

if condition1:
    # Code si condition1 est True
elif condition2:
    # Code si condition1 est False ET condition2 est True
elif condition3:
    # Code si condition1 et condition2 sont False ET condition3 est True
else:
    # Code si toutes les conditions sont False

Exemple 3 : Classification par note

note = 75
if note >= 90:
    print("Excellent")
elif note >= 80:
    print("Très bien")
elif note >= 70:
    print("Bien")
elif note >= 60:
    print("Passable")
else:
    print("Échec")

Explication : Avec note = 75, la première condition (>= 90) est fausse. La deuxième (>= 80) est aussi fausse. Mais la troisième (>= 70) est vraie, donc le programme affiche « Bien ».

Les opérateurs logiques : and, or, not

Parfois, vous avez besoin de combiner plusieurs conditions. Voici les opérateurs logiques :

and (ET) :

and signifie « toutes les conditions doivent être vraies ».

age = 25
has_license = True
if age >= 18 and has_license:
    print("Vous pouvez conduire")

Les deux conditions sont vraies, donc « Vous pouvez conduire » s'affiche.

or (OU) :

or signifie « au moins une condition doit être vraie ».

day = "samedi"
if day == "samedi" or day == "dimanche":
    print("C'est le week-end")

Si le jour est samedi OU dimanche, « C'est le week-end » s'affiche.

not (NON) :

not inverse le résultat : True devient False, et vice-versa.

is_raining = True
if not is_raining:
    print("Allons au parc")
else:
    print("Restons à la maison")

Comme is_raining est True, not is_raining est False. Donc « Restons à la maison » s'affiche.

Opérateur Signification Exemple Résultat
and ET logique True and True True
and ET logique True and False False
or OU logique False or True True
or OU logique False or False False
not Inversion not True False
not Inversion not False True

Quand utiliser if, elif, else ?

Voici un tableau récapitulatif :

Structure Quand l'utiliser Exemple
if Tester UNE seule condition « Affiche un message si l'âge ≥ 18 »
if ... else Faire quelque chose OU quelque chose d'autre « Si majeur, print 'Oui', sinon print 'Non' »
if ... elif ... else Tester PLUSIEURS chemins « Affiche différentes notes selon la moyenne »
and / or / not Combiner plusieurs conditions « Si âge ≥ 18 AND a_license, autorise »

Exemple pratique complet

Voici un programme qui utilise toutes les concepts :

Système d'accès à un cinéma

# Programme : Vérifier l'accès à un film
age = 16
has_ticket = True
is_alone = False

if age < 12:
    print("Films recommandés : Enfants")
elif age < 16:
    print("Films recommandés : Ados")
elif age < 18:
    if has_ticket and not is_alone:
        print("Accès autorisé avec un adulte")
    else:
        print("Accès refusé")
else:
    print("Accès autorisé (adulte)")

Explication pas à pas :

  1. age = 16 : L'utilisateur a 16 ans
  2. La première condition (age < 12) est False
  3. La deuxième condition (age < 16) est False
  4. La troisième condition (age < 18) est True
  5. On rentre dans ce bloc et on teste : has_ticket = True et not is_alone = True (car is_alone = False)
  6. Les deux conditions sont vraies (and), donc « Accès autorisé avec un adulte » s'affiche

Points clés à retenir

  • Une condition est toujours True (vrai) ou False (faux)
  • if exécute du code si la condition est vraie
  • else exécute du code si la condition est fausse
  • elif teste une autre condition si la première est fausse
  • Les opérateurs : ==, !=, >, <, >=, <=
  • and : toutes les conditions doivent être vraies
  • or : au moins une condition doit être vraie
  • not : inverse le résultat (True ↔ False)
  • L'indentation (espaces) est obligatoire après if, else, elif
