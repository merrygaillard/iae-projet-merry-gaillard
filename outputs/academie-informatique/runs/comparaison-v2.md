## Résumé détaillé

### Ce qu'A v2 a gagné

#### 1. **Structure guidée (Problème d'abord)**
```
A v1 : Introduction → Type 1 → Type 2 → Type 3 → Cas d'usage
A v2 : Problème concret → Solution → Explication détaillée → Tableau décisionnel
```

**Impact :** L'étudiant commence en disant « Je veux afficher 1–100 sans réécrire 100 fois » — c'est motivant et pertinent. À v1 commençait par une définition générale.

#### 2. **Tableau comparatif « Quel type choisir ? »**

A v1 : Absent (étudiant doit inférer)  
A v2 : Présent et clair (« Vous savez combien ? → for. Vous ne savez pas ? → while. C'est une liste ? → for...of »)

**Impact :** A v2 aide l'étudiant à décider, ce qui était le point fort de B.

#### 3. **Exemple appliqué concret (Somme d'une liste)**

A v1 : Table de multiplication, grille imbriquée  
A v2 : Idem + Somme d'une liste (très appliqué)

**Impact :** L'étudiant voit un pattern réaliste (accumulateur) qu'il reverra partout.

#### 4. **Meilleure organisation**

A v1 : « Voici 3 types → cas d'usage séparés »  
A v2 : « Voici le problème → 3 solutions → Quand utiliser quoi → Cas réaliste »

**Impact :** Plus fluide, moins cloisonné.

## Points clés appris

### Ce que cette comparaison démontre

1. **Les tests comparatifs révèlent la force pédagogique**
   - A v1 était bon mais manquait d'*orientation* (aider l'étudiant à décider)

   - On peut être exhaustif ET guidé (A v2 le prouve)
   - Guidé != court (A v2 = 18 min, B = 13 min, mais A v2 couvre plus)

3. **Les petites améliorations s'accumulent**
   - Tableau comparatif : +1 point

   - Structure guidée : +1 point
