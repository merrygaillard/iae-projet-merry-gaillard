C) let fonctionne seulement dans les fonctions
D) Aucune différence, c'est juste une question de style

QCM Moyen
Quel nom de variable respecte la convention de nommage JavaScript recommandée ?
A) let mon_nom = 'Tom';
B) let MontNom = 'Tom';
C) let monNom = 'Tom';
D) let monnom = 'Tom';
▶ Voir la solution
✅ Bonne réponse : C
JavaScript utilise la convention camelCase : la première lettre est minuscule, puis chaque nouveau mot commence par une majuscule (monNom, pas mon_nom, MontNom, ou monnom).
7
QCM Moyen
Qu'affiche ce code ? let x = 10; if (true) { let x = 20; console.log(x); } console.log(x);
A) 10 puis 10
B) 20 puis 10
C) 20 puis 20
D) Erreur
▶ Voir la solution
✅ Bonne réponse : B
À cause de la portée : le x déclaré dans le bloc {} est différent du x global. À l'intérieur du bloc, on affiche 20. Après, on affiche le x global qui est 10.

Pourquoi devez-vous toujours déclarer une variable avec let, const, ou var ?
A) C'est juste une convention, ce n'est pas obligatoire
B) JavaScript l'exige pour éviter les erreurs et la confusion
C) Pour rendre le code plus lisible
D) Parce que c'est plus rapide
▶ Voir la solution
✅ Bonne réponse : B
Si vous écrivez nom = 'Tom' sans let/const/var, vous créez une variable globale par accident. C'est dangereux car ça peut causer des bugs. Toujours déclarer explicitement.

Texte libre Difficile
Écrivez du code qui montre la différence entre portée globale et portée locale : - Déclarez une variable 'message' globale avec la valeur 'Globalement' - Créez une fonction qui déclare une variable 'message' locale avec 'Localement' - La fonction affiche le message local - Après la fonction, affiche le message global
▶ Voir la solution
✅ Exemple de solution :
let message = 'Globalement'; function afficherMessage() { let message = 'Localement'; console.log(message); } afficherMessage(); // Affiche: Localement console.log(message); // Affiche: Globalement
Explication : Cet exercice montre que même si les deux variables s'appellent 'message', elles sont différentes grâce à la portée. La variable locale (dans la fonction) n'affecte pas la globale.

Texte libre Difficile
Écrivez du code qui applique les bonnes pratiques vues dans la leçon : - Utilisez des noms de variables en camelCase - Utilisez let pour les variables qui changent, const pour les constantes - Créez au moins 3 variables - Affichez un résultat final avec console.log()
▶ Voir la solution
✅ Exemple de solution :
const tauxTVA = 0.20; let prixHT = 100; let prixTTC = prixHT * (1 + tauxTVA); console.log('Prix HT : ' + prixHT); console.log('Taux TVA : ' + tauxTVA * 100 + '%'); console.log('Prix TTC : ' + prixTTC);
Explication : Cet exercice teste votre compréhension globale : nommage (camelCase), choix de let/const, calculs, et affichage. Vous appliquez les bonnes pratiques vues dans la leçon.
