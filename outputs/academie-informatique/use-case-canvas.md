|---|---|---|
| Site d'apprentissage complet (30-35h) avec leçons + exercices de fin de leçon + exercices d'entraînement illimités. | *PROCESSUS ET ACTEURS* | *DONNÉES* | *IRRITANTS* |
| IA: recherche sources + synthèse contenu → rédaction leçons/exercices → génération QCM 50Q/niveau. Utilisateur: valide Excel sources (G1) → teste pôle-niveau (G2) → approuve site complet (G3) → déploie. Fallback si ressources insuffisantes (skip item, notifier) | Notes utilisateur optionnelles ; sources open source (MDN, W3Schools, Codecademy) ; Reddit/forums (validation avant inclusion) ; tableau Excel inventaire notions + sources ; contenu **français uniquement, code anglais** ; responsive web/tablette/mobile | Contenu fragmenté sur multiples sites ; sources de qualité variable/non fiables ; progression entre pôles opaque ; sources deviennent mortes/obsolètes ; maintenance continue requise |
| *RÈGLES* | *RISQUES* | *INDICATEURS DE RÉUSSITE* |
| Progression débutant→intermédiaire→avancé→bonus (bonus hors 30-35h) par pôle indépendant. Exercices: QCM (1 seule réponse correcte) + texte à trou + texte libre. QCM final 50Q/niveau (≥15/20 pour avancer). Chaque exercice: solution accessible au niveau. Sources toujours citées. Reddit→valider en sources traditionnelles avant inclusion. Si ressources manquent→fallback (skip, notifier). Sources mortes→remplacer | Sources inaccessibles/non fiables ; contenu trop facile/difficile/incomplet ; failles sécurité (XSS, SQL injection, input validation) ; pas de write systèmes externes ; pas de collecte données utilisateur. Scope : read-only, human-triggered, contenu public uniquement | **Mesure (1 semaine post-go-live)**: Heures apprentissage/semaine ≥ min 2h (obj 4h) ; Taux complétion par pôle mesurable. **Qualité**: AC1-AC7 ✓ (UX fluide web/tablette/mobile, exercices progressifs, pas risque sécurité, sources citées, feedback "Un commentaire ?") |
